# 1.1.3.2 Compléments Docker

## En bref

Ce document est la **fiche mémo** des commandes Docker les plus utilisées sur Hublot. Le détail (architecture des stages, NAS, dépannage) est dans le [Guide Docker](./1.1.3.1%20Guide%20Docker.md).

---

## Objectif pédagogique

Retrouver rapidement les **commandes opérationnelles** sans parcourir le guide complet.

---

## Contexte — projet Hublot

Au quotidien, l'équipe privilégie les **scripts npm** (`docker:dev`, `docker:prod`) ou **Make** si un `Makefile` est présent sur le poste. Les commandes ci-dessous sont équivalentes.

---

## Commandes essentielles

### Développement

```bash
npm run docker:dev
# Application : http://localhost:3000
```

### Production locale

```bash
npm run docker:prod:build
# Application : http://localhost:8080
```

### Preview test (build statique)

```bash
npm run test:preview:docker
# Application : http://localhost:4173
```

### Arrêt et logs

```bash
npm run docker:stop
npm run docker:logs
```

### Évolution des données

```bash
bash scripts/run-evolution-pipeline.sh --file "trdata/Suivi_des_emplois_en_ETPT_RPROG (23).xlsx"
```
